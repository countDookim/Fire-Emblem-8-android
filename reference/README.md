# reference/

Decomp-derived reference data, generated by `tools/gen_reference.py` and committed. Contains **no ROM
data** (only names, source locations and addresses). Regenerate only when the decomp pin changes.

| File | Columns | Source |
|---|---|---|
| `DECOMP_VERSION` | repo URL, commit | the fireemblem8u checkout |
| `decomp_functions.tsv` | name, file, line, kind (c/asm), system, address | parsed decomp sources + ELF symbols |
| `ram_symbols.tsv` | name, address, size, binding (global/local=`static`), region (ewram/iwram) | ELF symbols |
| `iwram_symbols.tsv` | name, address | decomp `sym_iwram.txt` (legacy; prefer ram_symbols.tsv) |

`decomp_functions.tsv` is the progress denominator (8352 functions). 15 functions have no address:
they are `static inline` or otherwise not emitted by the compiler; they still count.

## Regenerate
1. Bump `decomp/PIN` in the ROM repo → its `decomp-map` workflow builds the decomp (must be
   byte-identical to the ROM) and commits `decomp/fireemblem8.nm.txt` + `fireemblem8.map`.
2. `git clone https://github.com/FireEmblemUniverse/fireemblem8u /tmp/fe8u && git -C /tmp/fe8u checkout <pin>`
3. `python3 tools/gen_reference.py --decomp /tmp/fe8u --nm <rom-repo>/decomp/fireemblem8.nm.txt`
4. Record the bump in `docs/decisions/0007-decomp-choice.md`; review the diff of the function list.
